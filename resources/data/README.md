# Malaysia state boundaries

`malaysia-states.geojson` is the ADM1 state/federal-territory boundary dataset published by the Department of Statistics Malaysia (DOSM).

- Source: https://github.com/dosm-malaysia/data-open/blob/main/datasets/geodata/administrative_1_state.geojson
- Retrieved: 25 August 2026
- Repository licence: MIT (see the source repository's `LICENSE.md`)

The file is bundled locally so state exploration does not depend on a third-party service at runtime.
